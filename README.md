The system was built using C++ with a graphical interface and database integration.
### Technologies

- Object-Oriented Programming

- PostgreSQL
### Key Features

- Lost and found item reporting.
- Automated item matching.
- Claim verification workflow.

## Image Processing Application
### Overview
A C++ image processing application that performs basic image manipulation operations on PPM images.
Images are represented as a 3D matrix containing height, width, and RGB channels.
### Technologies
- C++
- OOP
- STL
- Matrix Representation
- Basic Image Processing
### My Contribution
Implemented the Horizontal Flip operation.
The function mirrors the image horizontally by mapping each pixel from:
(x, y) → (width - 1 - x, y)
while preserving image dimensions and RGB values.
